## Selected Projects / 项目展示

### [Subtitle Learning Agent | AI-assisted Japanese Study Prototype](https://github.com/ZhangMin3303/subtitle-learning-agent)

A personal local prototype for studying Japanese through audiovisual content while practising AI application engineering. Development used substantial AI assistance.

通过音视频学习日语，同时实践 AI 应用工程的个人本地原型；开发中使用了实质性的 AI 辅助。

- **Implemented / 已实现:** ASS parsing and bilingual merging, FFmpeg audio/video clips, a local study UI, and CSV-based human correction and rebuild workflows. / ASS 解析与双语合并、音视频切片、本地学习页、CSV 人工校对与数据重建。
- **Experimental / 实验中:** local ASR/OCR drafts; recognition quality remains unvalidated. NLP is limited to rule-based token previews and a small glossary. / ASR/OCR 仍为草稿，识别质量待验证；NLP 仅规则预览与小型词汇表。
- **Future / 规划:** reliable morphology, timeline correction and RAG. This is not a complete autonomous agent. / 可靠形态素分析、时间轴校准与 RAG 尚属规划，未实现完整自主 Agent。

### [Transfer Reinforcement Learning for Maze Path Planning](https://github.com/ZhangMin3303/rl-transfer-path-planning-thesis)

Undergraduate thesis work exploring Q-learning and transfer between maze layouts. The repository distinguishes historical code, later recovered/reviewed versions and selected validation checks; it does not establish a general performance improvement.

本科毕设：探索 Q-learning 与迷宫环境间的迁移。仓库区分历史代码、事后恢复/修订版本与选定验证，不将其表述为已证明的一般性能提升。

医学图像、信号处理与医学仪器相关课程/实验材料；代码来源与复现边界以仓库说明为准。
